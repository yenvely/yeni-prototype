### 1. 계정 및 회원 유형

**1.1 계정 정의**

- 이메일 주소당 1개의 사용자 계정 생성 가능
- 하나의 계정은 여러 워크플레이스에 동시에 소속될 수 없음
- 계정은 워크플레이스별로 서로 다른 역할(Role)을 가질 수 없음
- 하나의 계정은 소유자 역할과 멤버 역할을 동시에 가질 수 없음

**1.2 회원 유형 정의**

**소유자 (Workplace Owner)**

- 워크플레이스를 생성한 계정은 해당 워크플레이스의 소유자가 된다
- 소유자는 하나의 워크플레이스를 생성하고 소유가 가능
- 소유자는 멤버를 초대하고 각 멤버에게 권한을 부여할 수 있음
- 소유자는 다른 소유자로부터 초대를 받아 다른 워크플레이스의 멤버 역할을 동시에 가실 수 없음

**관리자 (Workplace Admin)**

- 소유자로부터 워크플레이스 권한을 부여받아 브랜드 관리 및 상담 데스크 운영 권한을 가진다.
- 계정 초대 및 브랜드 생성/삭제 등 일부 권한이 제한된다.

**멤버 (Workplace Member)**

- 소유자로부터 워크플레이스에 초대받아 가입한 계정은 해당 워크플레이스의 멤버가 된다.
- 워크플레이스에 초대된 멤버는 별도의 워크플레이스를 생성할 수 없으며, 다른 이메일 계정으로 신규 가입 후 워크플레이스를 생성해야 함

### 2. 회원가입 및 SSO 정책

**2.1 회원 가입 프로세스**

**일반 이메일 회원가입**

- **이메일 입력:** 유효성 체크(`@` 포함 등) 및 중복 가입 여부 확인
- **이메일 인증:** 30분 내 인증코드 입력 (5회 실패 시 세션 만료)
- **휴대폰 점유 인증:** SMS 인증 진행 (3분 유효, 일일 최대 5회 발송 제한)
- **정보 입력:** 이름(1~20자, 국/영/수), 비밀번호 설정(영대/소문자+숫자+기호 8~90자).
- **약관 동의:** 필수 약관 동의 후 가입 완료 및 워크플레이스 진입, 미소속 시 서비스 이용 제한

**SSO 회원가입**

- **계정 연동 지원 채널:** Google, Naver, Kakao
- **SSO 계정 연동**
- **휴대폰 점유 인증:** SMS 인증 진행 (3분 유효, 일일 최대 5회 발송 제한)
- **정보 입력:** 이름(1~20자, 국/영/수), 비밀번호 설정(영대/소문자+숫자+기호 8~90자).
- **약관 동의:** 필수 약관 동의 후 가입 완료 및 워크플레이스 진입, 미소속 시 서비스 이용 제한

**2.2 가입 항목 정책**

**이메일 주소**

- 유효하지 않은 이메일 주소 및 자동 생성된 이메일 주소(임시/가상 이메일)는 인증이 불가
- 입력 시 공백 허용 불가 및 `local-part@domain` 구조를 충족
- 등록된 이메일 주소로 가입 불가(중복 가입 불가)
- 탈퇴한 이메일 주소는 일정 기간(탈퇴일로부터 7일) 내 재가입 불가
- 제한 기간 동안 해당 이메일 계정은 “탈퇴 계정” 상태로 관리되며, 7일 이후 개인정보 파기 후 재가입 가능

**사용자 이름**

- 국문, 영문, 숫자로만 1자 이상 20자 이하로 입력 가능
- 20자를 초과할 경우 입력이 제한

**비밀번호**

- 비밀번호는 영문 대소문자,숫자,기호 포함하여 최소 8자 이상 최대 90자 이하로 입력 해야한다.
- 영문 대문자 (A–Z), 영문 소문자 (a–z), 숫자 (0–9), 기호 (`!@#$%^&*()_+-=[]{}|;:'",.<>/?` )로 설정 가능
- 비밀번호 설정 시 5자리 반복 및 연속 패턴은 사용 불가

**워크플레이스 명**

- 국문, 영문, 숫자로만 1자 이상 20자 이하로 입력 가능

### 3. 계정 통합

회원 가입 후 동일한 이메일 주소로 서로 다른 인증 수단(일반 회원가입,구글,네이버,카카오)로 다시 회원 가입을 시도할 경우 이를 하나의 고유 계정 식별자로 통합하여 동일한 데이터 와 워크플레이스 권한을 유지 할 수 있도록 제공

- **중복 체크 :** 기존 가입된 이메일 계정으로 서로 다른 인증 수단으로 회원가입 시도 시 이메일 주소 중복 체크
- (ex 문구 : 이미 가입된 이메일 주소입니다. 기존 계정과 통합하여 로그인하시겠습니까?)
- **인증 절차** : 일반 회원 - 비밀번호 입력, SSO 회원 - SSO 인증
- 계정 통합 후 일반 계정 로그인 ( 이메일 주소, PW) 또는 SSO 로그인 (계정 연동) 시 동일한 계정 정보로 로그인
