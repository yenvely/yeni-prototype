## 장기 미접속 계정 정책

### 1. 목적

- 장기간 서비스에 접속하지 않은 이용자의 개인정보를 안전하게 보호하고 관련 법령(개인정보보호법 및 내부 보안 정책)에 따라 계정을 관리하기 위함을 목적으로 한다.

### 2. 장기 미접속 기준

- 사용자가 1년 이상 로그인 기록이 없는 경우 마지막 로그인 일자를 기준으로 산정한다.

### 3. 장기 미접속 예정 안내

- 장기 미접속 계정 전환 30일 전 사전 안내 한다.
- 안내 내용에는 다음 항목을 포함한다.
    - 재가입 제한 기간: 탈퇴일로부터 7일
    - 제한 기간 동안 해당 이메일 계정은 “탈퇴 계정” 상태로 관리된다.
    - 탈퇴 회원에 대한 개인정보는 7일 이후 파기한다.
        - 탈퇴 회원 ISMS-P(정보보호 및 개인정보보호 관리체계) 기준
        - 개인정보 처리 목적이 달성되었거나 보유 기간이 종료된 개인정보는 지체 없이 파기한다.
    - 7일 이후에는 탈퇴 회원의 데이터 원천 소멸 후 신규 가입자로 가입된다.
- 안내 내용에는 다음 항목을 포함한다.
- 이메일 인증이 완료되면 사용자 이름을 입력한다.
- 비밀번호 설정 및 필수 약관에 동의한 후 회원가입을 완료한다.
- 회원가입 완료 후 사용자는 워크플레이스를 생성하거나, 해당 절차를 건너뛸 수 있다.
- 서비스 이용을 위해 서는 계정이 최소 1개 이상의 워크플레이스에 소유자 또는 멤버로 소속되어 있어야 한다.
- 서비스 이용을 위해서는 회원가입 후 워크플레이스 소속이 필수이며, 워크플레이스 미소속 상태에서는 서비스 이용이 제한된다.
- 사용자는 워크플레이스를 생성하여 소유자 권한으로 서비스를 이용하거나, 다른 소유자로부터 초대를 받아 멤버 권한으로 서비스를 이용할 수 있다.

### 4. 이메일 주소 정책

**4.1 이메일 입력 제한**

- 자동 생성된 이메일 주소(임시/가상 이메일)는 인증이 불가하다.
- 이메일 형식이 유효하지 않은 경우 인증을 진행할 수 없다.

**4.2 이메일 형식 유효성 조건**

- `local-part@domain` 구조를 충족해야 한다.
- `@` 문자는 반드시 1개만 포함되어야 한다.
- 공백은 허용하지 않는다.
- 도메인 규칙을 준수해야 한다.

**4.3 이메일 중복 및 재가입 제한**

- 이미 계정으로 등록된 이메일 주소로는 가입할 수 없다.
- 탈퇴한 이메일 주소는 일정 기간 재가입이 제한된다.
    - 재가입 제한 기간: 탈퇴일로부터 7일
    - 제한 기간 동안 해당 이메일 계정은 “탈퇴 계정” 상태로 관리된다.
    - 탈퇴 회원에 대한 개인정보는 7일 이후 파기한다.
        - 탈퇴 회원 ISMS-P(정보보호 및 개인정보보호 관리체계) 기준
        - 개인정보 처리 목적이 달성되었거나 보유 기간이 종료된 개인정보는 지체 없이 파기한다.
    - 7일 이후에는 탈퇴 회원의 데이터 원천 소멸 후 신규 가입자로 가입된다.

### 5. 이메일 인증 정책

**5.1 인증코드 발송**

- 유효한 이메일 주소 입력 시에만 인증코드를 발송한다.
- 자동 생성 이메일 주소 입력 시 인증코드 발송은 실패 처리된다.

**5.2 인증코드 유효기간**

- 인증코드 유효시간은 발송 시점부터 30분이다.
- 유효시간이 초과된 인증코드는 자동 만료되며 사용할 수 없다.

### 6. 사용자 정보 입력

**6.1 사용자 이름**

- 국문, 영문, 숫자로만 1자 이상 20자 이하로 입력 가능하다.
- 20자를 초과할 경우 입력이 제한된다
- 회원가입 완료 후 사용자 이름은 계정 관리 > 가입 정보 > 기본 정보 설정 에서 변경이 가능하다.

**6.2 비밀번호**

- 비밀번호는 영문 대소문자,숫자,기호 포함하여 최소 8자 이상 최대 90자 이하로 입력 해야한다.
- 영문 대문자 (A–Z), 영문 소문자 (a–z), 숫자 (0–9), 기호 (`!@#$%^&*()_+-=[]{}|;:'",.<>/?` )로 설정할 수 있다.
- 비밀번호 설정 시 5자리 반복 및 연속 패턴은 사용할 수 없다.
- 회원가입 완료 후 비밀번호 변경은 계정 관리 > 가입 정보 > 기본 정보 설정 에서 변경이 가능하다.

### 7. 워크플레이스 입력

**7.1 워크플레이스 명**

- 국문, 영문, 숫자로만 1자 이상 20자 이하로 입력 가능하다.
- 회원가입 완료 후 워크플레이스명은 계정 관리 > 가입 정보 > 기본 정보 설정 에서 변경이 가능하다.

### 8. 워크플레이스 가입 절차

**8.1 소유자**

- 워크플레이스를 생성한 계정은 해당 워크플레이스의 소유자가 된다.
- 다른 계정의 워크플레이스 가입은 초대 시에만 가능하다.

**8.1 CG에 가입된 멤버**

- 소유자가 소유한 워크플레이스에 멤버 초대를 위해 초대 메일을 발송한다.
- 초대받은 멤버는 초대 이메일에 포함된 인증 링크를 클릭한다.
- 해당 이메일 계정이 이미 회원으로 가입된 상태일 경우 로그인 페이지로 이동한다.
- 로그인 완료 후 초대받은 워크플레이스로 자동 이동한다.

**8.2 CG에 미가입된 멤버**

- 소유자로부터 발송된 워크플레이스 초대 이메일을 수신한다.
- 초대 이메일의 인증 링크를 클릭한다.
- 이메일 계정이 미가입 상태일 경우 회원가입 페이지로 이동한다.
- 회원가입 과정에서 초대받은 이메일 주소는 수정할 수 없다.
- 사용자 이름을 입력한다.
- 비밀번호 설정 및 약관 동의 후 회원가입을 완료한다.
- 회원가입 완료 후 초대받은 워크플레이스로 자동 이동한다.
