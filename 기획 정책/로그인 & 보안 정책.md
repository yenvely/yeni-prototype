

### 1. 로그인 항목 정의

- 이메일 주소를 사용하는 계정 정보를 입력한다.
- 설정한 비밀번호를 입력한다.
- 비밀번호 분실 시 비밀번호를 재설정할 수 있다.
- 비밀번호 재설정은 이메일 인증 절차 후 기존 비밀번호를 초기화하여 새로운 비밀번호로 재설정한다.
- 계정 및 비밀번호 입력 후 로그인 인증 시 소속 워크플레이스로 이동한다.

### 2. 비밀번호 정책

**2.1 비밀번호 설정**

- 비밀번호는 영문 대소문자,숫자,기호 포함하여 최소 8자 이상 최대 90자 이하로 입력 해야한다.
- 영문 대문자 (A–Z), 영문 소문자 (a–z), 숫자 (0–9), 기호 (`!@#$%^&*()_+-=[]{}|;:'",.<>/?` )로 설정할 수 있다.
- 비밀번호 설정 시 5자리 반복 및 연속 패턴은 사용할 수 없다.

**2.2 비밀번호 보안 정책**

- 비밀번호는 90일 주기로 변경해야 하며, 변경 주기 만료 시 사용자가 변경 또는 다음에 하기를 선택할 수 있다.
- 비밀번호 변경 후로부터 90일 이후 비밀번호 변경 안내 유도 팝업을 띄운다.
- 비밀번호 변경 90일 이후 다음에 하기 선택 시 변경 주기는 다시 초기화 된다.
- 비밀번호 변경 시 최근 사용한 비밀번호는 재사용이 불가하다.
- 비밀번호 변경 시 기존 계정 정보는 로그아웃된다.

### 3. 로그인 보안 정책

- 자동 로그아웃은 1시간, 6시간, 12시간, 24시간 단위로 설정할 수 있다.
- 자동 로그아웃은 관리자 설정 > 보안 관리 에서 설정할 수 있다.
- 워크플레이스 생성 시 자동으로 설정되는 자동 로그아웃 시간은 24시간이다.
- 사용자가 아무런 활동을 하지 않을 경우 설정한 시간이 경과하면 자동 로그아웃된다.
- 자동 로그아웃은 10분 전 안내 배너로 알림을 제공하며, 최대 7일까지 연장할 수 있다.
- 자동 연장은 최대 7일까지이며, 7일 이후에는 강제 자동 로그아웃 처리 된다.
- 자동 로그아웃 예외 기준
    - 자동 로그아웃 설정 후 사용자가 아래와 같은 활동 시 자동 로그아웃 설정 시간은 초기화된다.
    - 페이지 이동
    - 버튼 클릭
    - API 호출
    - 데이터 조회 및 저장
- 자동 로그아웃 시 저장되지 않은 데이터는 삭제된다.

### 4. 강제 로그아웃 정책

- 설정된 자동 로그아웃 시간이 경과되지 않더라도 아래와 같은 경우 강제 자동 로그아웃된다.
- 강제 로그아웃 기준
    - 비밀번호 변경 시 (회원 정보에서 계정 비밀번호 변경 시)
    - 비밀번호 재설정 시 (비밀번호 분실 후 비밀번호 재설정 시)
    - 회원 계정 탈퇴 및 가입된 워크플레이스에서 나갈 시
    - 로그인 2단계 설정 시
    - 자동 로그아웃 설정 변경 시
    - 접속 IP 설정 시
    - 워크플레이스 권한 변경 시

### 5. 다중 로그인 설정 정책

- 여러 기기 또는 브라우저의 동시 로그인 허용은 불가하다.
- 동시 로그인 접속 시 기존 기기 또는 브라우저의 로그인 세션은 종료된다.

### 6. 브라우저 종료 시 세션 정책

- 브라우저 탭 닫기 시 기존 세션은 유지한다.
- 브라우저 완전 종료 시 세션 종료 및 로그아웃 처리된다.

## 데이터 파기 정책

### 1. 회원 탈퇴 시 개인정보 파기 정책

- 회원 탈퇴 시 즉시 계정은 로그아웃되며, 모든 서비스의 이용이 불가하다.
    
- 회원 탈퇴 시 개인 정보는 즉시 파기되며, 복구는 불가하다.
    
- 회원 탈퇴 시 개인 정보 파기 항목
    
    |항목|내용|
    |---|---|
    |계정 인증 정보|비밀번호, 이메일 인증 토큰|
    |프로필 정보|이메일 주소, 휴대폰 번호, 이름|
    |마케팅 수신 정보|광고 수신 동의 이력|
    
- 7일 이내 동일한 이메일 주소로 재가입은 불가하다.
    

### 2. 워크플레이스 삭제 시 데이터 파기 정책

- 소유자 계정

### 3. 브랜드 삭제 시 데이터 파기 정책

- 브랜드 내 모든 상담 이력은 삭제 된다.
- 자동 로그아웃은 관리자 설정 > 보안 관리 에서 설정할 수 있다.

### 4. 상담 이력 데이터 삭제 정책

- 상담 이력은 보관 기간(3년) 후 보관 기간 만료 시 삭제한다.
- 삭제 데이터
    - 채팅 상담 내역
    - 티켓 내역
    - 상담 녹취 이력
    - 콜 상담 이력
