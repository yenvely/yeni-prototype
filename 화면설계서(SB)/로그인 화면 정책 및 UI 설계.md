        # 로그인 화면 정책 설계 및 UI 설계

> 참고 문서 : `Yeni's Note > UIUX 설계 > 로그인`
> 작성일 : 2026-05-15

---

## 1. 화면 개요

| 항목 | 내용 |
|------|------|
| 화면명 | 로그인 |
| 화면 ID | SCR-LOGIN-001 |
| 접근 경로 | 서비스 최초 진입 / 세션 만료 후 자동 리디렉션 |
| 목적 | 등록된 계정(이메일 + 비밀번호)으로 사용자 인증 후 워크플레이스 진입 |

---

## 2. 화면 구성 요소

### 2-1. 입력 필드

#### [1] 이메일
- 필수 입력 항목
- Placeholder : `이메일 주소를 입력하세요.`
- 화면 진입 시 자동 포커싱 처리
- 입력 형식 유효성 검사 (이메일 형식)

#### [2] 비밀번호
- 필수 입력 항목
- Placeholder : `비밀번호를 입력하세요.`
- 기본값 : 입력 데이터 마스킹 처리 (●●●●●●)
- **미리보기 버튼** : 상시 노출, 선택 시 입력 데이터 평문 표시
- `Enter` 키 입력 시 → [3] 로그인 버튼 클릭과 동일하게 처리

---

### 2-2. 버튼

#### [3] 로그인 버튼
- 기본 상태 : 활성화
- 클릭 시 아래 케이스별 정책 적용

---

## 3. 로그인 버튼 케이스 정책

### #C01. 이메일·비밀번호 정상 입력 시

| 케이스 | 조건 | 처리 |
|--------|------|------|
| ① | 이메일이 워크플레이스에 소속된 경우 | 해당 이메일과 매핑된 워크플레이스의 **대시보드 화면**으로 이동 |
| ② | 이메일이 워크플레이스에 미소속된 경우 | **워크플레이스 생성 화면**으로 이동 |

> **[3-1] Error msg** : 필수 입력 항목입니다. *(이메일 또는 비밀번호 미입력 시)*

---

### #C02. 케이스별 팝업 출력

| 케이스 ID | 조건                              | 팝업 내용                                       |
| ------ | ------------------------------- | ------------------------------------------- |
| [3-2]  | DB에 미등록된 아이디 입력 + 비밀번호 오류 5회 미만 | 이메일 또는 비밀번호를 확인해주세요.                        |
| [3-3]  | 비밀번호 오류 5회 이상                   | 비밀번호 오류 횟수 초과 안내 + 비밀번호 재설정 유도              |
| [3-4]  | 탈퇴된 계정 (탈퇴일로부터 7일간 재가입 제한)      | 탈퇴 처리된 계정입니다. 탈퇴일로부터 7일 이후 재가입이 가능합니다.      |
| [3-5]  | 비밀번호 변경일 이후 +90일 경과             | 비밀번호 변경 후 90일이 경과하였습니다. 비밀번호를 변경해주세요.       |
| [3-6]  | 계정이 비활성화 처리된 경우                 | 비활성화된 계정입니다. 관리자에게 문의해주세요.                  |
| [3-7]  | 접속 허용 IP가 아닌 경우                 | 허용되지 않은 IP에서의 접속입니다.                        |
| [3-8]  | 중복 로그인 시도                       | 다른 기기에서 이미 로그인 중입니다. 기존 세션을 종료하고 로그인하시겠습니까? |

---

## 4. 자동 로그아웃 정책

| 케이스 | 조건 | 처리 |
|--------|------|------|
| #C01 다른 계정에서 강제 로그인 | 타 기기·계정에서 강제 로그인 발생 | [7-1] 자동 로그아웃 팝업 출력 |
| #C02 설정한 자동 로그아웃 시간 도래 | 관리자 설정 시간 경과 | [7-2] 자동 로그아웃 팝업 출력 |
| #C03 워크플레이스 권한 변경 | 사용자 권한이 변경된 경우 | [7-3] 자동 로그아웃 팝업 출력 |

> **자동 로그아웃 시간 단위** : 1시간 / 6시간 / 12시간 / 24시간 (관리자 설정 > 보안 관리에서 설정 가능)

## 5. UI 설계

### 5-1. 레이아웃 구조

```
┌─────────────────────────────────────────┐
│                                         │
│           [서비스 로고]                  │
│                                         │
│  ┌─────────────────────────────────┐    │
│  │  이메일 주소를 입력하세요.        │    │  ← [1] 이메일 입력
│  └─────────────────────────────────┘    │
│                                         │
│  ┌──────────────────────────── 👁 ┐    │
│  │  비밀번호를 입력하세요.          │    │  ← [2] 비밀번호 입력 + 미리보기
│  └─────────────────────────────────┘    │
│                                         │
│  ┌─────────────────────────────────┐    │
│  │           로그인                │    │  ← [3] 로그인 버튼
│  └─────────────────────────────────┘    │
│                                         │
│       비밀번호를 잊으셨나요?             │  ← 비밀번호 찾기 링크
│                                         │
└─────────────────────────────────────────┘
```

---

### 5-2. 컴포넌트 상태 정의

#### 이메일 입력 필드

| 상태 | 설명 |
|------|------|
| Default | 기본 테두리, placeholder 표시 |
| Focus | 테두리 강조 (Primary Color), placeholder 유지 |
| Filled | 입력값 표시 |
| Error | 빨간 테두리 + 하단 에러 메시지 표시 |

#### 비밀번호 입력 필드

| 상태            | 설명                                |
| ------------- | --------------------------------- |
| Default       | 기본 테두리, placeholder 표시, 👁 아이콘 표시 |
| Focus         | 테두리 강조                            |
| Filled (마스킹)  | ●●●●●● 표시, 👁 아이콘 활성              |
| Filled (미리보기) | 평문 표시, 👁‍🗨 아이콘으로 변경             |
| Error         | 빨간 테두리 + 하단 에러 메시지 표시             |

#### 로그인 버튼

| 상태 | 설명 |
|------|------|
| Default / Active | Primary Color, 텍스트 흰색 |
| Hover | 약간 어두운 Primary Color |
| Loading | 스피너 표시, 버튼 비활성 |

---

### 5-3. 에러 메시지 위치

```
┌─────────────────────────────────────┐
│  이메일 주소를 입력하세요.            │
└─────────────────────────────────────┘
  ⚠ 필수 입력 항목입니다.              ← 필드 하단 좌측 정렬, 빨간색
```

---

### 5-4. 팝업 구조 (케이스별 공통)

```
┌──────────────────────────────────┐
│                                  │
│   [아이콘]   팝업 제목            │
│                                  │
│   본문 메시지                     │
│                                  │
│        [ 확인 ]  [ 취소 ]        │
│                                  │
└──────────────────────────────────┘
```

> 단순 안내 팝업 : 확인 버튼만 노출
> 선택이 필요한 팝업 (ex. [3-8] 중복 로그인) : 확인 + 취소 버튼 노출

---

## 6. 접근성 고려사항

- 이메일 입력란에 화면 진입 시 자동 포커스
- 에러 상태 시 스크린리더를 위한 `aria-invalid`, `aria-describedby` 적용
- 버튼 및 아이콘에 `aria-label` 명시
- 키보드 Tab 순서 : 이메일 → 비밀번호 → 미리보기 버튼 → 로그인 버튼 → 비밀번호 찾기

---

## 7. 연관 화면

| 이동 대상 | 조건 |
|-----------|------|
| 대시보드 | 로그인 성공 + 워크플레이스 소속 |
| 워크플레이스 생성 | 로그인 성공 + 워크플레이스 미소속 |
| 비밀번호 재설정 | 비밀번호 찾기 클릭 / 오류 5회 초과 |
| 로그인 화면 (리로드) | 자동 로그아웃 팝업 확인 후 |
