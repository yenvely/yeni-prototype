
### **아이디 찾기**

1. [입력] 이름 
- 필수 입력 항목 
- place holder text : 이름을 입력하세요. 
- 입력 조건 : 입력 제한 없음 
- 규칙 위배 시 에러메시지 적용  
  - [1-1] 미입력 : 필수 입력 항목입니다.   
2. [입력] 휴대폰 번호 
- 필수 입력 항목 
- place holder text : 휴대폰 번호를 입력하세요. 
- 입력 조건 : 11자리 숫자  
  ① 11자리 초과 시 추가 입력 불가  
  ② 숫자 입력 시 3-4-4 형태로 자동 하이픈 적용  
      ex) 010-2222-3333  
- 규칙 위배 시 에러메시지 적용  
  - [2-1] 미입력 : 필수 입력 항목입니다.  
  - 2-2] 조건 미충족 : 휴대폰 번호를 확인하세요.  

3. [버튼] 아이디 찾기 
   -  항상 활성화 상태 
   - 버튼 선택 시 Validation Check 진행되며 케이스별 기능 적용  
    #C01. 회원 정보 정상 입력  
    ① 배경 Dimmed 처리 및 [3-1] 아이디 안내 팝업 출력  
    - 이름과 휴대폰 번호와 매핑된 이메일 정보 API 호출하여 출력
    - 가입 방법 + 아이디 일부 + 도메인 (가입일)   ex) abc***@gmail.com (YYYY-MM-DD 가입)  
    - 가입 방법 : 일반가입, 네이버, 카카오, 구글  
    ② 같은 이름과 휴대폰 번호로 가입된 정보가 2건 이상인 경우  
    - [3-3] 정렬 기준 : 가입일 기준이며 오름차순으로 정렬  
    #C03 회원 정보 불일치  
    ① 입력한 이름과 휴대폰 번호에 매핑된 계정 미존재 
    - [3-4] 불일치 안내 팝업 출력  
3. [버튼] 확인 
   - 선택 시 해당 팝업 닫힘 처리되며 로그인 화면으로 이동 
3.  [버튼] 확인 
- 선택 시 해당 팝업 닫힘 처리되며 ‘아이디 찾기’ 화면 유지
