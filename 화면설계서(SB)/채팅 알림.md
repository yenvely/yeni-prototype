   ① 채팅 팝업 재오픈
   ② 팝업내의 Action Button 선택 
3. [카운팅] 진행중인 상담 
   - [3-1] 현재 상담중인 건수 + [3-2] 이관된 건수 출력  
     - 채팅상담 : 웹챗, 카카오, 네이버 톡톡 (챗봇, 이메일은 제외)  
4. [카운팅] 나에게 할당된 상담
   - [4-1] ‘나에게 할당된 상담’ 건수 출력
5. 목록
   - 상담 상태가 ‘상담중/이관/할당’ 인 채팅상담 목록 출력  
    - 채팅상담 : 웹챗, 카카오, 네이버 톡톡 (챗봇, 이메일은 제외)  
     ① 상담 중  - 신규 채팅상담 인입  
     - 진행중인 상담에서 신규 메시지 인입  
     ② 나에게 할당된 채팅상담  
     ③ 이관된 채팅상담 ・정렬 기준 : 인입 시간 기준 내림차순으로 정렬(최신순)   
6. 채팅 상담 
    #Case01 인입된 채팅이 없는 경우  
    - [2-1] Empty 아이콘 & 텍스트 적용  
    #Case02 인입된 채팅이 있는 경우 
    - 인입된 채팅 상담의 정보 출력  
     ① [2-2] 브랜드 프로필  
     - 브랜드 이미지 미등록 : ‘브랜드명' 첫 글자 노출 
     ② [2-3] 인입 채널 
     - 웹챗 : Default 아이콘 노출 (상담사 이미지 등록해도 사용자 화면에만 노출)  
     - 카카오톡 상담톡 : Kakao Default 아이콘 노출  
     - 네이버 톡톡 : Naver Default 아이콘 노출  
     ③ [2-4] 고객명, 상담상태(상담중/이관/할당) 노출  
     - 고객명이 1행 초과 시 ...처리 (최대 n자 기준 적용) 
     ④ [2-5] 브랜드명> 상담유형  
      - [1-1] 스크롤 시 페이지 호출하여 목록 출력
7. 신규 채팅 인입 
     - N뱃지 적용 기준  
     - ‘상담 시작전' 상태의 채팅에만 적용  
       ① 신규로 인입된 채팅 상담  
       ② 나에게 할당/이관된 신규 채팅
8. 카운팅 배지 
   - 미확인 메시지가 있는 채팅방에 적용  
   - 채팅방의 메시지 확인 시 카운팅 삭제 
    ① 채팅방 진입 시 ‘카운팅’ 초기화
    ② 상담데스크 > 해당 채팅방에서 ‘메시지’ 확인 시 초기화

1. [버튼] 상담 종료
   - 선택 시 설문조사 사용 여부에 따라 분기 처리 
   - 채팅 상담데스크와 동일한 정책 적용 
    #### C01. 설문조사 미사용 
    ① [1-1] 상담 종료 안내 팝업 출력 
    #### C02. 설문조사 사용 
    ① [1-2] 설문조사 링크 전송 팝업 출력  
    - 상담사가 상담 종료 시 발송 여부 선택 가능 
    ② 설문조사 자동 발송  
    - 고객이 종료  
    - 상담 인사말 이후  
    - 상담 대기 메시지 이후 
    ③ 설문조사 미발송한 경우  
    - 티켓 메뉴에서 ‘설문조사’ 발송 가능  
2. [버튼] 종료
    - 선택 시 아래의 기능 적용
    ① [2-1] 후처리 상태로 변경되며 팝업 닫힘 처리  
    ② [2-2] 상담종료 상태 메시지 출력   
    ③ [3] ‘상담 데스크로 이동’ 버튼 제공  
    - 메시지 입력영역은 UI에 미노출 
3. [버튼] 상담 데스크로 이동 
    - 선택 시 채팅 상담 데스크 화면으로 이동 
    - 화면 이동 후 [3-1] 해당 채팅방 OPEN 처리

1. 새로운 메시지 
   - 스크롤 위치가 최하단이 아닌 상태에서 신규 메시지 수신 시 출력  
   - ‘가장 최근에 수신된 메시지’ 1건만 표시  
   - 메시지가 1행 초과 시 ...적용
   - 선택 시 해당 메시지 위치로 스크롤 이동 후 [1] 메시지 삭제 
   - 스크롤이 최하단으로 이동한 경우 [1] 메시지 삭제   
2. 파일 전송 
   - 고객이 파일(동영상/이미지)를 전송한 경우
3. [알림] 금칙어 
   - 고객 메시지 내 금칙어가 포함된 경우 [1] 알림 제공 
   - UI 정책  
     - 화면에서 고정 (fixed) 
     - 스크롤 시에도 위치 유지  
     - 사이즈 고정 / 중앙 정렬 
     - 상담 말풍선 
     - 하얀색 글씨 / 언더라인 노출 하여 직접적으로 가독이 되지 않도록 
     - 드래그할 경우에만 금칙어 확인 가능
4. [버튼] X 
    -  선택 시 닫힘 처리 
    - 동일 메시지에 대해서는 재노출하지 않음 ・신규 금칙어 메시지 수신 시 다시 노출
 5. [버튼] 상담 더보기 
    - 상담메시지 100개 초과한 경우 
    - 상담 상태가 ‘상담 완료’ 인 경우에만 노출 
    - 클릭 시 이전 메시지 100개 단위로 추가 노출 
    - 해당 채팅방의 모든 메시지가 모두 출력된 경우 ‘더보기' 버튼 미노출
6. [버튼] ↓
    - 과거 메시지 확인 중에 최신 메시지로 빠르게 이동할 수 있도록 버튼 제공
    - 사용자가 위 방향으로 스크롤한 상태  
      - 소폭만 위로 스크롤한 이동한 경우에는 미노출
