  
1. 초대 이메일 
   - 워크플레이스의 소유자가 멤버로 초대 시 ‘초대 메일’ 발송
2. 이메일 주소 
    - 멤버로 초대된 [1-2] 이메일 주소 출력
3. 워크플레이스명 
   - 워크플레이스명 출력
1. [버튼] 클라우드게이트 시작하기 
    - 선택 시 케이스별 분기 처리 
    #C01 CG미가입
     ① 조건 : DB에 등록되지 않은 이메일 
     ② 선택 시 [4-1] ‘회원가입 방법 선택' 화면으로 이동  
   #C02 CG회원
    ① 조건 : 로그인한 계정이 CG회원가입 완료 (DB에 등록된 이메일) 
    ② 선택 시 [3-1] 계정 안내 화면으로 이동 
    #C03 초대 유효시간 만료  
    ① [4-3] 새창으로 CG 접속 > 초대 만료 화면 출력 
    - [확인]버튼 선택 시 ‘로그인' 화면으로 이동
        ✔️ Check List  ① 소유자 > 멤버 초대 
        #01. 초대할 이메일이 DB에 등록되지 않은 경우
        #02. 이메일이 DB에 등록되어 있는 경우에는 워크플레이스에 미소속된 회원만 초대 가능  워크플레이스에 미소속된 CG회원은 초대 시 즉시 워크플레이스에 참여 처리

# 초대 > 회원가입 > 분기 처리 
1.  워크플레이스명 ・초대받은 워크플레이스명 출력   
2.  워크플레이스 참여 방법 ・구글, 네이버, 카카오, 일반   
3.  클라우드 게이트 
- 선택 시 회원가입 화면으로 이동
  
# 초대 > 이미 가입된 계정
1. 가입된 계정 안내
 - 초대된 계정이 이미 클라우드 게이트에 가입된 경우 
 - CG 회원의 로그인 계정에 매핑된 정보 출력   
   - [1-1] 이메일, 가입일자, 가입 방법(일반가입, 구글, 네이버, 카카오)   
2. [버튼] 로그인하기 
   - 선택 시 로그인화면으로 이동
