
이메일 인증
1. 이메일 
   - 필수 입력 항목
   - Place holder text : 이메일 주소를 입력하세요.
   - 입력 조건 : local-part@domain 구조 충족, @ 1개만 포함(공백 미허용) 
   - 데이터 입력 시 Validation Check 진행 ・케이스별로 아래의 기능 적용
      ① 규칙 위배   - 에러 메시지 및 아이콘 적용  
      #C01  [1-1] 미입력 
      #C02 [1-2] 입력 데이터 규칙 위배  
      #C03 [1-3] 자동 생성된 이메일 주소(임시/가상 이메일) 
      #C04 [1-4] 이미 가입된 이메일 주소 
      #C05 [1-5] 탈퇴 계정 (탈퇴일로부터 7일)  
    - 7일 이후에는 신규 가입자로 가입 가능  
     ② 정상 입력  
     - [2] 보내기 버튼 활성화되며 [Enter] 입력 시 ‘보내기' 버튼 클릭 처리  
2. 보내기 
   -  활성화 조건 : 이메일 주소 정상 입력  
   - 버튼 선택 시 아래의 기능 적용 
    ① 재입력 버튼으로 변경 
    ② 이메일 Input Box 비활성화 처리 
    ③ 이메일 인증번호 Input Box 활성화처리 
    ④ 이메일로 인증번호 발송 
    - 입력한 이메일로 ‘인증번호' 발송(DB에서 6자리 숫자로 랜덤 전송)  
    - 시간은 버튼 클릭 한 시점으로 부터 +30분 출력  
    ⑤ 인증번호 발송 완료 메시지 출력  
    ⑥ 남은시간 카운트 다운   
    - 인증코드 유효시간 30분 초과 시 자동 만료 
    - 남은시간은 ‘보내기' 버튼 클릭 시점으로부터 +30분 카운팅
    - 1초 단위로 카운트다운 (29분 59초, 29분 28초, 29분 27초 ...)   
    ⑦ 재전송 기능 제공 
    - 선택 시 해당 이메일에 인증번호 재전송 및 인증시간 초기화
    - 최대 5회 발송 제한 (5회 이상 선택 시 disable 처리)
3. 재입력 
   - 선택 시 이메일에 전송된 인증번호 초기화 되며 Default 적용 
4.  이메일 인증번호 
   - 필수 입력 항목 
   - 활성화 조건 : 이메일로 인증번호 전송 완료 
   - Place holder text : 인증번호를 입력하세요. 
   - 입력 조건 : 숫자만 입력 가능 (마스킹 처리 ❌)  
    최대 6자리만 입력 가능하며 추가 입력 제한 
5.  인증
   -  인증번호는 30분 동안 유효하며 5회까지 입력 가능 
   - 활성화 조건 : 이메일 인증번호 6자리 숫자 입력 
   - 선택 시 인증번호 Validation Check 진행  
   #C01 인증 완료 
    ① 비활성화 : 이메일/이메일 인증번호 Input Box, [인증] 버튼   
    ② 활성화 : [재입력] 버튼 
    ③ 인증번호 정상 입력 시 안내 메시지 출력  MSG : 인증이 완료되었습니다.  
    ④ 남은시간 만료 처리  
#C02 인증번호 불일치
    ① 인증번호 오류 입력 시 에러메시지 출력  MSG : 인증번호가 일치하지 않습니다. (1/5)
    ② 입력된 인증번호 전체 삭제 시 남은시간, [재전송] 기능 제공  
#C03. [5-3] 인증 횟수 초과 (5회 실패) 
    ① 안내 팝업 출력  - 확인 선택 시 이메일, 이메일 인증번호 Default 상태로 변경  
     - 인증번호 및 인증시간 만료 처리 
#C04  [5-4] 인증코드 유효시간 만료  
    ① 인증코드 발급 후 30분 경과 시 자동 만료 
     -  ‘인증시간 초과’ 안내 메시지 출력 및 재전송 기능 제공 
       MSG : 인증 시간이 만료되었습니다. 다시 요청해 주세요.  
    ② 메일로 발송된 인증번호 초기화 및 인증시간 만료 처리 
    ③ 비활성화 : 이메일 Input Box, [인증] 버튼 
    ④ 활성화 : 이메일 인증번호 input Box (Place holder text 적용)



# 휴대폰 인증

1.  휴대폰 번호 ・필수 입력 항목
  - Place holder text : ‘-’를 제외하고 숫자만 입력하세요. 
  - 입력 조건 : 11자리 숫자 (숫자만 입력 가능)  
  - 숫자 입력 시 3-4-4 형식에 맞게 자동 하이픈 적용  ex) 010-2222-2222 
  - 데이터 입력 시 Validation Check 진행 
  - 케이스별로 아래의 기능 적용  
    ① 규칙 위배   - 에러 메시지 및 아이콘 적용  
    #C01 미입력 
    #C02 입력 데이터 규칙 위배
    #C03 탈퇴 계정 (탈퇴일로부터 7일)  
    - 7일 이후에는 신규 가입자로 가입 가능  
    ② 정상 입력  - [2] 보내기 버튼 활성화되며 [Enter] 입력 시 ‘보내기' 버튼 클릭 처리   
2. 보내기 
    ・활성화 조건 : ‘휴대폰 번호' 정상 입력  ・버튼 선택 시 아래의 기능 적용 
    ① [3] 재입력 버튼으로 변경  
    ② [2-1] 휴대폰 번호 Input Box 비활성화 처리  
    ③ [4] 휴대폰 인증번호 Input Box 활성화처리  
    ④ 입력한 휴대폰 번호로 [2-2] 인증번호 발송 
     - ‘인증번호' 발송(DB에서 6자리 숫자로 랜덤 전송) 
     - 유효시간은 버튼 클릭 한 시점으로 부터 +3분 출력  
    ⑤ [2-3] 인증번호 발송 완료 메시지 출력  
    ⑥ 남은시간 카운트 다운   
    - 인증코드 유효시간 3분 초과 시 자동 만료  
    - 남은시간은 ‘보내기' 버튼 클릭 시점으로부터 5분 카운팅   
    - 1초 단위로 카운트다운 (2분 59초, 2분 28초, 2분 27초 ...)   
    ⑦ [2-4] 재전송 기능 제공 
    - 선택 시 입력한 휴대폰 번호에 인증번호 재전송 및 인증시간 초기화 
    ⑧ 인증번호 발송은 1일 최대 5회 가능하며 초과 시 [2-5] 에러 메시지 출력 
3. 재입력
   - 선택 시 입력한 휴대폰 번호에 전송된 인증번호 초기화 되며 Default 적용 
4. 휴대폰 인증번호 
   - 필수 입력 항목
   - 활성화 조건 : 휴대폰으로 인증번호 전송 완료 
   - Place holder text : 인증번호를 입력하세요. 
   - 입력 조건 : 숫자만 입력 가능 (마스킹 처리 ❌)  

   - 최대 6자리만 입력 가능하며 추가 입력 제한  
5. 인증 
   - 활성화 조건 : 인증번호 6자리 숫자 입력 ・선택 시 인증번호 Validation Check 진행   
   #C01 [5-1] 인증 완료  
    ① 비활성화 : 휴대폰 번호/ 휴대폰 인증번호 Input Box, [인증] 버튼   
    ② 활성화 : [재입력] 버튼  
    ③ 인증번호 정상 입력 시 안내 메시지 출력  MSG : 인증이 완료되었습니다.  
    ④ 남은시간 만료 처리 
   #C02[5-2] 인증번호 불일치  
    ① 인증번호 오류 입력 시 에러메시지 출력  MSG : 인증번호가 일치하지 않습니다.  
    ② 입력된 인증번호 전체 삭제 시 남은시간, [재전송] 기능 제공 
6. 인증번호 만료
    ① ‘인증시간 초과’ 안내 메시지 출력 및 재전송 기능 제공 
    MSG : 인증 시간이 만료되었습니다. 다시 요청해 주세요.  
    ② 문자로 발송된 인증번호 초기화 및 인증시간 만료 처리  
    ③ 비활성화 : 휴대폰 번호 Input Box, [인증] 버튼   
    ④ 활성화 : 휴대폰 인증번호 input Box (Place holder text 적용)



# 비밀번호

1. 비밀번호 
   - 필수 입력 항목 
   - ・회원가입 완료 후 변경 가능  
     - 변경 Depth : 대시보드 (Top Header) > 비밀번호 변경
     - Place holder text : 문자, 숫자, 기호를 조합해 8자 이상 비밀번호를 입력하세요. 
     - 입력 조건   
     ① 규칙 : 영문 대소문자, 숫자, 기호 포함 8자 이상~ 90자 이하  
        - 영문 대문자 (A–Z), 영문 소문자 (a–z), 숫자 (0–9), 기호 (!@#$%^&*()_+-=[]{}|;:'",.<>/?)  
        - 5자리 반복 및 연속 패턴은 사용 불가  
        - Default : 데이터 입력 시 마스킹 처리  
        - 미리보기 버튼은 상시 노출되며 선택 시 입력 데이터 UI에 노출  
        -  데이터 입력 시 Validation Check 진행  
        - 규칙 위배 시 에러 메시지 출력  
          ① [1-1] 미입력 : 필수 입력 항목입니다. 
          ② [1-2] 규칙 위배 : 영문/숫자/기호 조합의 8~90자로 입력하세요. 
2. 이름 
   -  필수 입력 항목
   - 회원가입 완료 후 변경 가능  
     - 변경 Depth : 대시보드 (Top Header) > 프로필 설정  
     - Place holder text : 이름을 입력하세요. 
     - 입력 조건   
      ① 규칙 : 한글, 영문, 숫자 최소 1자 이상 ~ 최대 20자 이하  - 20자 초과 입력 제한  
      - 규칙 위배 시 에러 메시지 출력  
      - 데이터 입력 시 Validation Check 진행  
      ① 미입력 : 필수 입력 항목입니다.  
      ② 규칙 위배 (한글, 영문, 숫자 외 데이터 입력 


# 약관동의

     - [1-1] 보기 선택 시 새창으로 약관 출력 링크 이동
     - 개인정보 수집 및 이용 동의 (필수)  
       - [1-2] 보기 선택 시 새창으로 약관 출력 링크 이동
     - 마케팅 활용 동의 및 광고 수신 동의 (선택)
2.  가입하기 
     - 활성화 조건 : 필수입력 항목 모두 정상 입력
       ① 이름, 비밀번호, 비밀번호 확인
       ② 회원가입 및 이용약관  
       ③ 개인정보 수집 및 이용동의 
     - 버튼 선택 시 아래의 기능 적용  
       ① 로그인 화면으로 이동 후 가입완료 안내 팝업 출력   
       ② 회원가입 시 입력한 이메일로 회원가입 완료 안내 메일 발송 
3. 로그인 
   - 선택 시 로그인 화면으로 이동
