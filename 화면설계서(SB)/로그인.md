# Email 2단계 인증

1. 로그인 2단계 > 이메일 인증
    ① 로그인 시 이메일 인증 화면으로 이동 
    - CG > 보안 관리 > 로그인 2단계 인증에서 ‘사용함'으로 설정된 경우
    ② 프로필에서 이미 이메일 인증을 한 경우 
    - 인증 1단계는 생략되며 바로 이메일 인증 2단계로 넘어감 
    - 이 경우 이미 가입한 이메일로 인증을 완료한 케이스라 최초 가입한 이메일로 인증번호가 수신됨  
2. [조회] 이메일
    - 로그인 계정에 매핑된 이메일 출력
    - 수정 불가(Read Only)  
3. [버튼] 동의 후 인증하기
   - 버튼 선택 시 아래의 기능 적용
   ① [3-1] 이메일로 인증 번호 발송
   ② 이메일 인증번호 입력 화면으로 이동
   ③ 남은시간 카운트다운 
    - 버튼 클릭 시점으로 부터 +10분


## 이메일 인증번호 입력 

1. [입력] 인증번호 
   - 필수 입력 항목 ・Place holder text : 인증번호를 입력하세요.
   - 입력 조건 : 숫자만 입력 가능 (마스킹 처리 ❌) 
   - 최대 6자리만 입력 가능하며 추가 입력 제한   
2. [버튼] 인증하기 
   - 활성화 조건 : 6자리 숫자 입력 
   - 선택 시 케이스별로 기능 적용 
   #C01 중복 로그인  
   ① CG에 로그인 되어있던 계정이 존재하는 경우 
   - [2-1] 안내 팝업 출력 
   - [2-2] 확인 버튼 선택 시 로그인되어있는 계정 로그아웃 처리 
   - [2-3] 취소 버튼 선택 시 팝업 닫힘 처리
   #C02 인증번호 오입력 
   ① [2-4] 로그인 불가 안내 팝업 출력  
   - [2-5] 확인 버튼 선택 시 팝업 닫힘 처리 & [1] 인증번호 / 남은시간 초기화 처리   
   #C03 인증번호 정상 입력 
   ① 워크플레이스에 소속된 CG 회원 : 해당 워크플레이스의 대시보드로 이동 
   ② 워크플레이스에 미소속된 CG 회원 : ‘워크플레이스 생성’ 화면으로 이동   
3. 인증 시간 초과 
   ① 인증 시간 (10분) 초과된 경우 [3-1] 화면으로 전환
