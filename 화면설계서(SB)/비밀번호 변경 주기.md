 1. 비밀번호 재설정 
    - 로그인 시 비밀번호 변경 안내 팝업 출력 
    - 비밀번호 최초 설정 및 변경일로부터 +90일 이후 (금일 포함하여 +90 카운팅)   
2. [버튼] 확인 
    -  비밀번호 변경 화면으로 이동   
3. [버튼] 취소 
    - 선택 시 팝업 닫힘 처리 및 로그인 화면 유지


### 비밀번호 변경 안내

1. 비밀번호 변경 안내
    - 90일 주기로 비밀번호를 변경해야되며 다음에하기 or 변경 선택 가능   
2.  [입력] 비밀번호 
    - 필수 입력 항목 
    - Place holder text : 비밀번호를 입력하세요. 
    - ・입력 조건  ① 규칙 : 영문 대소문자, 숫자, 기호 포함 8자 이상 90자 이하
    - 영문 대문자 (A–Z), 영문 소문자 (a–z), 숫자 (0–9), 기호 (!@#$%^&*()_+-=[]{}|;:'",.<>/?) 
    - 5자리 반복 및 연속 패턴은 사용 불가
    - Default : 데이터 입력 시 마스킹 처리  
      - 미리보기 버튼은 상시 노출되며 선택 시 입력 데이터 UI에 노출
      - 규칙 위배 시 에러메시지 출력  
        ① [2-1] 미입력 : 필수 입력 항목입니다.  
        ② [2-2] 규칙 위배 : 영문/숫자기호 조합의 80~90자로 입력하세요.  
3. [입력] 비밀번호 확인
     - 필수 입력 항목 
     - Place holder text : 비밀번호를 한번 더 입력하세요. 
     - 입력 조건   
     - 규칙 : [1] 비밀번호에 입력한 데이터와 동일 
      - Default : 데이터 입력 시 마스킹 처리 
      - 미리보기 버튼은 상시 노출되며 선택 시 입력 데이터 UI에 노출 
      - 데이터 입력 시 Validation Check 진행  
      - 규칙 위배 시 에러 메시지 출력  
        ① [3-1] 미입력 : 필수 입력 항목입니다.  
        ② [3-2] 규칙 위배 : 비밀번호가 일치하지 않습니다. 
4. [버튼] 다음에 하기
    -  선택 시 비밀번호 변경 주기는 +90일로 초기화 처리  
      - 금일 포함 +90일 24:00 
5. [버튼] 변경  
     - 활성화 조건 : 비밀번호, 비밀번호 확인 모두 정상 입력  
     - 선택 시 아래의 케이스별로 기능 적용  
    #C01. 최근 비밀번호와 동일한 경우  
     ① [5-1] ‘사용 불가' 안내 팝업 출력  
        - [5-2] 확인 버튼 선택 시 팝업 닫힘 처리 
    #C02 정상적으로 변경 완료  
    ① [5-3] ‘변경 완료' 안내 팝업 출력  
    - [5-4] 확인 버튼 선택 시 로그인 화면으로 이동  
    ② DB에 설정한 비밀번호 업데이트 처리
    ③ 로그인 화면으로 이동 
    ④ 비밀번호 변경 주기는 +90일로 초기화 처리
