1. 콜 ・활성화 : 콜 수신중  
   - [1-1] 애니메이션 + 하이라이트 적용 
   - 선택 시 [2] 콜 팝업 출력되며 재클릭 시 팝업 닫힘 처리  
2. [팝업] 콜
   - Drag 시 화면 내에서 이동 가능 
   - 콜 팝업이 Open 상태에서 메뉴 이동 시 유지 
   - [2-1] 고객 정보(이름, 연락처) 및 콜 상태(수신중) 출력  
3. [버튼] 콜 상담 데스크로 이동 
  - 선택 시 콜 상담 데스크로 이동하며 현재 콜 유지 (수신중 / 통화중) 
4. [버튼] 통화하기 
  - 선택 시 콜 상태를 ‘통화중' 으로 변경 
  - [4-1] 콜 상담 데스크에도 동일하게 ‘통화중' 상태로 반영 
  5. [버튼] X ・선택 시 콜 팝업 닫힘 처리
  -  콜은 종료되지 않고 백그라운드에서 유지 
  - 수신중 상태에서 팝업을 닫은 경우에 도 [1-1] 적용

    #C03 비정상 종료   
    - 시스템 또는 환경 이슈로 종료된 경우   
2. 후처리  
    -  통화종료 상태 : 후처리 기능 제공 
    - 선택 시 ‘후처리' [2-1] 상담 내용 입력 새창 출력  
      - URL이 없는 새창 팝업 출력 
      - 새창 OPEN 상태에서 [2]버튼 클릭 시 닫힘 처리 
      - ’후처리’는 콜상담데스크와 UI 및 기능 동일하게 적용 
      - 후처리 미진행 ❌ : Top header > call 팝업 접근 시 [1]팝업 출력 
3. [버튼] 저장 
     - 선택 시 ‘콜 상담데스크 > 후처리’와 기능 동일하게 적용 
     ① [2-1] 상담 내용 입력 화면에 입력한 데이트 DB에 업데이트  
     ② [2-1] 새창 + [1] 콜팝업 닫힘 처리  
     ③ [3-1] 등록 완료 팝업 출력  
      - 확인 버튼 선택 시 팝업 닫힘 처리  ④ 상태 변경 : 후처리 → 상담완료
